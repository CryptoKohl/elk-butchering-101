Elk Butchering 101: install it

One-time setup, about a minute. After it, the app opens from your home screen like any app, full screen, keeps the screen on while you cut, and still opens if the garage Wi-Fi drops.

1. Trust Kassandra

Your phone needs Kassandra's certificate so it can talk to it securely.

Download Kassandra's certificate
Android (Samsung, Pixel)
  1. Tap the button above. It saves to Downloads.
  2. Open Settings and search for CA certificate (on Samsung: Security and privacy → More security settings → Install from device storage → CA certificate).
  3. Tap Install anyway, then pick Kassandra-home-CA.crt.
iPhone
  1. Open this page in Safari, tap the button above, then Allow and Close.
  2. Open Settings, tap Profile Downloaded near the top, then Install.
  3. Settings → General → About → Certificate Trust Settings → turn on Kassandra home CA.

This certificate only works for Kassandra (10.98.1.210). It can't be used for any other website. To remove it later: Settings → search "user certificates" (Android) or Settings → General → VPN & Device Management (iPhone).

2. Open the secure app and add it to your home screen

Open https://10.98.1.210:8443
  1. Android, Chrome: ⋮ menu → Add to home screen → Install.
  2. iPhone, Safari: Share → Add to Home Screen.

If the secure link shows a warning, step 1 isn't finished yet. The old address, http://10.98.1.210:8090, keeps working too.
